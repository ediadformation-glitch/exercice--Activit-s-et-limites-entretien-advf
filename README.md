# Mise en ligne sur GitHub Pages

1. Créez un nouveau dépôt sur GitHub.
2. Déposez `index.html`, `styles.css`, `app.js` et `README.md` à la racine du dépôt.
3. Dans **Settings → Pages**, choisissez **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`.
4. Enregistrez : l’URL publique apparaît dans la section **Pages** après quelques instants.
